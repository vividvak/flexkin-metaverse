# FLEXKIN Private Spa — 배경음악

`flexkin-spa.mp3`는 FLEXKIN 메타버스 전용으로 만든 오리지널 곡입니다. 외부 음원은 쓰지 않았습니다.

- D♭ 장조 · 60 BPM · 192초 · 끝과 처음이 이어지도록 만든 반복용 곡
- 구성: 따뜻한 앰비언트 패드, 펠트 피아노(드문드문 화음을 짚는 정도), 낮은 베이스, 아주 옅은 공기음, 홀 잔향
- `compose.py`로 다시 만들 수 있습니다: `python3 compose.py flexkin-spa.wav` 후 MP3로 변환
- 다른 곡으로 바꾸려면 같은 이름(`flexkin-spa.mp3`)으로 이 폴더에 덮어쓰면 됩니다.
