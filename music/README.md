# 배경음악 넣는 곳

이 폴더에 음원 파일을 **`flexkin-spa.mp3`** 라는 이름으로 넣으면 메타버스 전체에서 재생됩니다.

- 경로: `music/flexkin-spa.mp3` (index.html 기준)
- 권장: MP3, 128–192kbps, 3–8분, 앞뒤에 무음 없는 Ambient 트랙 (끝 6초가 처음과 자동으로 겹쳐져 반복 지점이 드러나지 않습니다)
- 용량: 10MB 이하 권장 (모바일 로딩)
- 상업적 사용이 허용된 라이선스의 음원만 사용하고, 라이선스 증빙(구매 영수증·라이선스 페이지 캡처)은 별도로 보관하세요.
- 파일이 없으면 음악 버튼이 숨겨지고 나머지 기능은 그대로 작동합니다.
