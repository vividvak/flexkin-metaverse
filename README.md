# EXPERT FLEXKIN 3D 힐링 관리실

피부 고민을 고르면 관리대에 누운 고객에게 약 2~3분 동안 단계별 관리가 이어지는 3D 웹 체험입니다. three.js로 만들었고, 서버 없이 정적 파일만으로 동작합니다.

## 실행
- GitHub Pages 주소로 열면 바로 실행됩니다.
- 로컬에서는 폴더에서 `python3 -m http.server` 를 실행한 뒤 `http://localhost:8000` 을 엽니다. (파일을 더블클릭해 `file://`로 열면 제품 사진이 3D 진열대에 표시되지 않을 수 있습니다.)

## 수정하기
- 관리 문구, 피부 고민 버튼, 단계, 홈케어 가이드, 제품 이름·사진·링크: `index.html` 안의 `<script id="flexkin-care-data">` 블록
- 추천 제품 링크: 같은 블록의 `FLEXKIN_LINKS`
- 자막 속도: 같은 블록의 `FLEXKIN_SESSION.pace`
- 제품 사진: `products/` 폴더 (배경을 지운 WebP)

## 참고
- 음악은 브라우저 정책상 화면을 처음 터치한 뒤부터 재생됩니다.
- 여러 명 동시 접속(관리실 공유)은 claude.ai 아티팩트 안에서만 동작합니다. 이 사이트에서는 각자 혼자 보는 모드로 열립니다.
